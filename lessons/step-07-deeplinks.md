# Шаг 07: прямые ссылки на задания НМТ

Дата: 2026-11-09. Статус: утверждён Conductor 2026-11-09 как есть, работа сделана (`lessons/record-07.md`). Языки: uk и ru.

## Цель

Каждая ссылка сайта на задание НМТ ведёт прямо на это задание: `https://zno.osvita.ua/mathematics/846/#q3` вместо `https://zno.osvita.ua/mathematics/846/` (пример Conductor 2026-11-09).

## Как

Адрес ссылки берётся из столбца `url` среза `lessons/nmt-slice.tsv`; движок (`tools/build-sources.py`) только копирует его. Правка - данные сайта: к адресу каждой из 132 строк дописывается `#q<n>`, где n - номер задания в строке; затем пересборка страниц. Движок не правится. Якоря проверены по сохранённым копиям (`/home/ik/lab/downloads/nmt-math/zno-osvita/t<вариант>.html`): в каждом из шести вариантов есть `id="q1"` … `id="q22"`, номер совпадает с номером задания.

## Три условия готовности

1. **Адреса (машиной):** во всех 132 строках среза `url` имеет вид `https://zno.osvita.ua/mathematics/<test>/#q<n>` с числами своей строки; каждая ссылка на zno.osvita.ua в разделе внешних ссылок страниц uk и ru несёт `#q<N>`, где N - номер задания из текста ссылки.
2. **Якоря существуют:** для каждой ссылки в сохранённой копии её варианта есть `id="q<N>"` (машиной, без запросов к сайту); одна проверка в браузере - ссылка на вариант 846 `#q3` показывает задание 3.
3. **Проверки:** `./check.sh` печатает ЗЕЛЁНОЕ на всех строках; движок не тронут.
