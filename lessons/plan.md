## Условия шага 3 (профиль в ростке)

Инженерная серия не ломается ни вперёд, ни назад (Conductor, 2026-11-08):

1. Сайт без строки `profile` в `site.conf` считается `assess`. Ни один готовый сайт не
   правится, чтобы остаться зелёным.
2. `sync.sh` по-прежнему раздаёт движок всем сайтам; часть профиля - только сайтам этого
   профиля.
3. **Предикат приёмки:** `./check.sh` на копиях всех существующих инженерных сайтов до и после
   изменения ростка даёт построчно одинаковый итог.
4. Перед началом: в родительском репо есть незакоммиченные правки `seed/swa/AGENTS.md`,
   `bootstrap.sh`, `sync.sh`, сделанные не в этой сессии. Их коммитит или откладывает Conductor.

4. Навигатор с линзами предмета вместо DevOps/SRE.
5. Исходный язык `uk`, второй `ru`; `en`/`de` - решить.

## Находки для ростка (движок, касаются всей серии)

1. **(Исправлено, e25152a.) Запасной счётчик слов в `assets/swa.js` не видел кириллицу.** Регулярка `/[^\W_]/` без
   флага `u` в JavaScript понимает `\w` только как ASCII, поэтому украинская или русская
   страница без запечённого числа показывает «Слів: 234» вместо 1217. На сайтах серии число
   обычно печёт `tools/build-meta.py`, и запасной путь не срабатывает, поэтому ошибка не
   видна. Исправление в одну строку (`/[^\W_]/u` не поможет: нужен `/[\p{L}\p{N}]/u`).
   Не исправлено: движок не правится из сайта.
2. **Десятичная запятая в формулах.** `0{,}25` в конвертере даёт `<mo>,</mo>` с пробелом
   оператора, и читатель видит «0, 25». Работает `0\text{,}25`. Для украинской и русской
   математики это каждое второе число; профилю `study` нужна либо подсказка в уставе, либо
   замена в `build-math.py`.
3. В `style.css` нет стилей для `<details>`; в прототипе они в `proto.css`.
