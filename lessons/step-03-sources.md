# Шаг 03: срез НМТ, внешние источники, настройки (рабочая записка, для продолжения после сжатия контекста)

Дата: 2026-11-09. Порядок, принятый Conductor: (1) срез НМТ 2024-2026, (2) рисунки в задачах по приоритетам среза,
(3) английская версия.

## Готово

- `lessons/nmt-slice.tsv`: 132 задания 6 основных сессий (2024-2026, по 2 на год), разметка законами сайта,
  `missing:` для тем без закона (28 заданий), строки `#missing` с украинскими и русскими названиями тем.
  Получено 8 запросами к zno.osvita.ua (robots.txt, список сессий, 6 страниц тестов), 5 с между запросами.
  Платные «Пояснення» на страницах не использованы.
- Движок: `tools/examslice.py`, вторая цифра в `tools/build-frequency.py` (блоки и посадочная), исправление видов
  страниц в `tools/build-search.py`.
- Движок, без подключения: `tools/build-sources.py`, раздел «Завдання НМТ на закони цього блоку» с блоками
  `<div class="ext" data-ext="nmt-ua:YYYY" id="exam-YYYY">` по годам и `<meta name="swa-sources">` на всех страницах.

## Осталось (фича внешних источников, требования Conductor)

1. `assets/sources.js` (движок): шестерёнка в `.utility-tray`, окно настроек с группами; группа «Зовнішні джерела»:
   флажок источника «Сайт ЗНО-ОНЛАЙН (zno.osvita.ua)» и **флажок на каждый год**. Хранение:
   `localStorage swa-<site>-ext-off` (JSON-список `nmt-ua:2026` …). Применение: `hidden` у `.ext[data-ext]`,
   показ `.ext-off` при выключенном источнике. Без `meta swa-sources` скрипт ничего не делает.
2. Поиск (движок): `build-search.py` индексирует каждый `.ext` отдельной записью с видом `x:nmt-ua:YYYY` и кладёт
   подписи в `window.SEARCH.x` (только если такие есть - инженерные индексы не меняются); `search.js` показывает
   фильтр на каждый год, только для включённых в настройках, и не ищет в выключенных.
3. Стили в `assets/study.css`: `.ext`, шестерёнка, окно настроек. Подключить `sources.js` на страницах учебного
   профиля (`new-site.py` и `build-nav.py` ASSETS), в `nmt-math` добавить `<script>` во все страницы.
4. `check.sh`: строка `build-sources.py --check` только для профиля `study` (как частота).
5. Сборщик сайта (скретчпад `site/build.py`) - добавить `tools/build-sources.py` после `build-frequency.py`.
6. Регрессия инженерной серии (скрипт `regress.sh` в скретчпаде), полный `./check.sh`, браузер, коммиты по видам.

Потом: рисунки в задачах (по 48 заданиям НМТ с рисунком и частоте законов), английская версия.
